# Product Catalog Fullstack - (test description)
Fullstack web application for managing products built with ASP.NET Core Web API and React.

## Features

* Product management (create, edit, soft delete, list)
* Product comments system
* Product categories
* Pagination and product filtering
* User authentication with roles (admin / user)

## Tech Stack

Backend:

* ASP.NET Core Web API
* Entity Framework Core
* LINQ
* MS SQL Server

Frontend:

* React
* TypeScript / JavaScript
* REST API communication

Tools:

* Swagger
* Postman
* Git & GitHub

## Database Entities

* Product
* Comment
* Category
* User

## How to Run the Project

1. Clone the repository
2. Run the backend server (ASP.NET Core)
3. Run the React frontend
4. Open the application in the browser

## Project Purpose

This project was created as part of a web programming course and demonstrates building a fullstack application with a REST API and database integration.
